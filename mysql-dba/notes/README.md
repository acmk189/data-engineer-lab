# notes/

実験の予想と結果、自分の言葉での説明を書く場所。1章1ファイルにして、`12.md` のように章の番号をファイル名にする。

**業務の Aurora で見た値（設定値、件数、クエリ）は、ここにも書かない。** このリポジトリは公開している。業務の Aurora で確かめたことは、「どの値を見たら何が分かったか」だけを書く。

## 雛形

```markdown
# 12 redo ログとクラッシュリカバリ

## 実験1: （実験の名前）

- 予想:
- 結果:
- 自分の言葉で:

## 説明できるか確かめる

1.
2.
3.

## この章でいちばん大事だと思ったこと

```

実験の結果は、数字そのものより「何と比べてどうだったか」を書く。あとで読み返したときに、何を確かめたのかが分かるようにする。
