# rdbms/

MySQL の実行計画とチューニングを扱う（W3〜W4）。**中身はまだ作っていない。W3 の前の週末に追加する。**

予定している内容:

- `EXPLAIN` / `EXPLAIN ANALYZE` の読み方（アクセス方法、結合の順番、行数の見積もり）
- インデックスを足す前後の比較。このリポジトリの MySQL は、そのために主キー以外のインデックスを張っていない
- `sql/` で解いた問題（自己結合、相関サブクエリなど）が MySQL でどう実行されるか。`spark/05_sql_plans.ipynb` と見比べる
- DDIA「ストレージと検索」の内容（B-tree と LSM、行指向と列指向、OLTP と OLAP）との対応
- チューニングの記録の型（対象・原因・対応・前後の数字）。業務のクエリやデータそのものは、ここには置かない
